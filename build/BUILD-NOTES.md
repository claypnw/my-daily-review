# Build notes — My Daily Review

- `build/add_skip_player.py` — the standing program that adds the pop-up seven-button story player to a finished review page.
- `build/daily-review-build-2026-11-14.py` — the review itself is built by a dated build program, one per day, on Muse's side; this is today's, standing as the pattern. A new day starts by copying the newest dated build and adjusting it.
The finished review page is what this repository publishes.
